# Tabi Kelvin Ayomide — Portfolio

A responsive portfolio showcasing selected web products and case studies.

Live site: https://tabi-kelvin-portfolio.vercel.app/

## Run locally

This is a static HTML, CSS and JavaScript site. From this directory run `python -m http.server 8000`, then visit http://localhost:8000.

The résumé is in `output/pdf/` and project images are in `portfolio-assets/`.
